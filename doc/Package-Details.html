Function Details

Lab1_quickBox

A boxplot function that accepts values.

Lab2_zScore

Finds z-scores for values.

Lab3_quickPlot

Returns a line plot (with steelblue!)

Lab4_fitVsResPlot

Creates residual vs fitted plot with a linear model.

Lab5_mybin

Creates a barplot displaying relative frequency.

Lab6_myncurve

Creates a density plot using dnorm given a mean and standard deviation

Lab8_mycltb

Density plot with central limit theorem.

myboot2

Creates a bootstrap density plot with confidence intervals.

mymaxlik

Findings maximum likelihood.

project1_ntickets

Calculates the number of tickets to be sold when the number of seats in the flight.

Data Details

Fire

A data set collected containing fire DAMAGE and DISTANCE from fire stations.
